# Курсовая работа

## Вариант

Разработка клиентской и серверной части приложения "Платформа для ведения личного бюджета и учета расходов"

## Задание

- Доменная модель. Модель данных должна содержать не менее трех сущностей: одна основная, две вспомогательные. Между основной и вспомогательными сущностями должна существовать связь «один-ко-многим».
Персистентность данных на основе JPA для каждой сущности.
- Доступ к данным должен осуществляться через DAO для каждой сущности.
- Бизнес-логика должна быть выделена в отдельные классы для каждой сущности.
- Контроллеры для взаимодействия с приложением через REST API для каждой сущности.
- Необходимо использовать DTO и валидацию для всех контроллеров.
- Клиентская часть приложения на React для работы со всеми сущностями.

## Стек

Backend: Java, Spring. Frontend: JS, React.
